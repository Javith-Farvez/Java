## Problem Description

Given marks M (0 to 100), assign a grade using the following criteria:
- M >= 90: Grade A
- 80 <= M < 90: Grade B
- 70 <= M < 80: Grade C
- 60 <= M < 70: Grade D
- 50 <= M < 60: Grade E
- M < 50: Fail
Print the corresponding grade or "Fail".

## Explanation

85 is between 80 and 89, so the result is Grade B.
